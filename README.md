# Breast Cancer Survival Analysis | Excel Dashboard

## Project Overview

This project analyses a dataset of 5,000 breast cancer patient records to explore survival outcomes, recurrence patterns, treatment performance, cancer stages and patient demographics.

The aim was to transform the raw data into an interactive Excel dashboard that makes key patterns and insights easy to understand.

## Dashboard

![Breast Cancer Survival Analysis Dashboard](breast%20cancer%20dashboard.png)

## Key Insights

- Overall survival rate: 75%
- Overall recurrence rate: 30%
- Average tumour size: 4.28 cm
- Monthly survival peaked at approximately 81% in August
- Stage 2 represented the largest proportion of patients at 29%
- Patient outcomes were compared across treatment types
- Recurrence cases were analysed across cancer stages
- Patient distribution was examined across age groups
